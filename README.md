# NEXUS CONTROL

**Windows control center for RDP, SSH and Wake-on-LAN.**

Все ваши компьютеры — в одном месте. NEXUS CONTROL сохраняет устройства, показывает доступность RDP и SSH, открывает системные клиенты Windows и помогает включить компьютер перед подключением.

Для домашних и рабочих ПК, серверов и небольших лабораторий. Подходит тем, кто уже использует удалённый доступ и хочет быстрее переключаться между собственными или разрешёнными компьютерами.

## Возможности

- **Сохранённые компьютеры.** Имена, адреса, возможности и заметки в удобных карточках.
- **Доступность RDP и SSH.** Проверка нужной службы перед подключением.
- **Удалённый рабочий стол.** Запуск стандартного RDP-клиента Windows.
- **SSH-терминал.** Системный OpenSSH, Windows Terminal или стандартная консоль.
- **Wake-on-LAN.** Отправка Magic Packet по сохранённым параметрам устройства.
- **Включить → дождаться → подключиться.** Готовые сценарии для RDP и SSH с возможностью отмены.
- **NEXUS GUIDE.** Локальный справочник с поиском, быстрыми инструкциями и диагностикой.
- **Настройки внешнего вида.** Полные, спокойные или минимальные эффекты; обычная или компактная плотность интерфейса.

## Как это работает

Добавьте устройство и укажите его параметры. NEXUS проверит доступность выбранной службы: сначала по локальному адресу, затем по дополнительному адресу, если он задан. Для подключения приложение открывает системный клиент; авторизация проходит в самом клиенте.

В сценарии пробуждения NEXUS отправляет Wake-on-LAN, ждёт доступности RDP или SSH до 90 секунд и открывает соответствующий клиент. Уже открытая удалённая сессия работает независимо от NEXUS.

Ответ TCP-порта подтверждает доступность службы, а отправка Magic Packet — отправку пакета. Эти состояния сами по себе не подтверждают успешный вход или включение ПК.

## Быстрый старт

1. Откройте [релиз 1.0.0-rc.1](https://github.com/Ziganshin23432423/nexus-control/releases/tag/v1.0.0-rc.1) и скачайте **NEXUS-CONTROL-Windows-x64-1.0.0-rc.1.zip** из раздела **Assets**.
2. **Полностью распакуйте ZIP** в отдельную папку.
3. Запустите **NEXUS CONTROL.exe** из распакованной папки.
4. В разделе **«Мои компьютеры»** нажмите **«Добавить компьютер»**, сохраните адрес и нужные возможности.
5. Обновите статус и выберите рабочий стол, терминал или пробуждение.

**Сохраняйте все файлы и папки рядом с EXE.** Не переносите один EXE отдельно и не удаляйте папку `resources`, библиотеки и остальные компоненты. Для перемещения приложения переносите всю распакованную папку.

Для готовой сборки не нужны Node.js, npm или installer. Подробнее — в [краткой инструкции](docs/quick-start.md).

## Платформа и требования

| Компонент | Требование |
|---|---|
| Компьютер с NEXUS | Windows 10/11 x64. Текущий выпуск — Release Candidate. |
| Сеть | Доступ к целевому устройству по локальной сети или через уже настроенный VPN. |
| RDP | На целевом ПК включён удалённый рабочий стол и разрешён ваш пользователь. Windows Pro, Enterprise, Education или подходящая Windows Server; Windows Home не принимает входящие RDP-подключения. |
| SSH | Системный OpenSSH Client на ПК с NEXUS и настроенный SSH-сервер на целевом устройстве. |
| Wake-on-LAN | Совместимые BIOS/UEFI, сетевой адаптер и сеть; сохранённые MAC и broadcast-адрес. |

Используйте возможности по необходимости: SSH и Wake-on-LAN не обязательны для подключения по RDP. Параметры и подготовка устройств описаны в [настройке сети](docs/network-setup.md).

## Безопасность и приватность

NEXUS CONTROL работает с локальными данными. Облачная учётная запись NEXUS не требуется; приложение не отправляет телеметрию и не хранит пароли Windows или SSH. Для базовых возможностей не нужен отдельный агент NEXUS на целевом ПК.

Список устройств и параметры подключения сохраняются на вашем компьютере. RDP и SSH используют обычную авторизацию системных клиентов. Приложение не настраивает автоматически VPN, firewall, службы Windows или BIOS.

Используйте NEXUS только для собственных устройств и устройств, на доступ к которым у вас есть разрешение. [Подробнее о безопасности и сообщении об уязвимости](SECURITY.md).

## Ограничения Release Candidate

- Выпуск предварительный; поведение на вашем оборудовании и в вашей сети нужно проверить перед регулярным использованием.
- Сборка не подписана цифровым сертификатом. Windows может показать предупреждение SmartScreen или сообщение о репутации файла.
- Wake-on-LAN зависит от BIOS/UEFI, адаптера, состояния питания и доставки пакета в целевую сеть. Доступный VPN сам по себе не гарантирует WoL.
- RDP требует подходящей редакции Windows на целевом ПК и разрешённого доступа. SSH требует установленного клиента и настроенного сервера.
- Проверки доступности не являются постоянным фоновым мониторингом. Linux-версия приложения в этом выпуске не предлагается.
- Основная поставка — ZIP с приложением; installer и автоматическое обновление в этом выпуске не предоставляются.

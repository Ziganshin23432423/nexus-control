# Подготовить другой ПК

NEXUS использует уже настроенные RDP, SSH и Wake-on-LAN. Настройте только те возможности, которые нужны для устройства.

## Параметры для карточки

| Параметр | Что собрать |
|---|---|
| Название | Понятное имя устройства. |
| Локальный адрес | IPv4 или доступный hostname. |
| Дополнительный адрес | При необходимости — адрес устройства в настроенном VPN или другой разрешённой сети. |
| SSH username | Имя пользователя на целевом устройстве, если нужен SSH. |
| MAC | MAC нужного сетевого адаптера, если нужен WoL. |
| Подсеть и broadcast | Маска подсети и соответствующий broadcast IPv4. В карточку записывается broadcast. |
| WoL-порт | Используемый UDP-порт; обычно 9. |

## RDP

На целевом Windows-ПК откройте **Параметры → Система → Удалённый рабочий стол**, включите доступ и разрешите нужного пользователя. Проверьте доступность устройства в вашей сети и разрешения firewall.

Входящие RDP-подключения поддерживаются в Windows Pro, Enterprise, Education и Windows Server. Windows Home может использоваться как клиент, но не как RDP-host. NEXUS проверяет стандартный порт **3389**.

[Официальная инструкция Microsoft](https://learn.microsoft.com/en-us/windows-server/remote/remote-desktop-services/remotepc/remote-desktop-allow-access).

## SSH

На ПК с NEXUS должен быть установлен системный **OpenSSH Client**. На целевом устройстве нужен настроенный SSH-сервер с доступом для вашего пользователя. Для Windows это компонент **OpenSSH Server** и работающая служба `sshd`. NEXUS проверяет стандартный порт **22**.

При наличии Windows Terminal приложение открывает SSH в нём; иначе используется стандартная консоль. Проверка host key и авторизация остаются в OpenSSH.

[Официальная инструкция Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse).

## Wake-on-LAN

Включите соответствующую поддержку в BIOS/UEFI и настройках сетевого адаптера по инструкции производителя. Сохраните MAC и корректный broadcast-адрес. Убедитесь, что сеть доставляет пакет к адаптеру.

Пробуждение зависит от модели ПК, адаптера, состояния питания и сети. VPN и маршрутизаторы могут не передавать broadcast; наличие связи с включённым ПК не гарантирует возможность его пробудить.

## Если устройство недоступно

Проверьте питание, адрес и доступ через локальную сеть или VPN, затем соответствующую службу и разрешения доступа. Для WoL отдельно проверьте MAC, broadcast и поддержку пробуждения. Не отключайте защитные настройки целиком для устранения ошибки: ограничивайте изменения нужной службой и разрешённой сетью.

Для дальнейшей диагностики используйте встроенный NEXUS GUIDE или [создайте Issue](https://github.com/Ziganshin23432423/nexus-control/issues) без личных данных.

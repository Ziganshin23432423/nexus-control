# Быстрый старт

## Запуск

1. В [релизе 1.0.0-rc.1](https://github.com/Ziganshin23432423/nexus-control/releases/tag/v1.0.0-rc.1) скачайте `NEXUS-CONTROL-Windows-x64-1.0.0-rc.1.zip` из **Assets**.
2. Полностью распакуйте архив в новую папку. Не запускайте приложение прямо из ZIP.
3. Откройте `NEXUS CONTROL.exe`.

Все файлы должны оставаться рядом с EXE, включая `resources`, DLL и уведомления о лицензиях. Если переносите приложение, переносите всю папку. Node.js, npm и installer не нужны.

Windows может показать предупреждение о неподписанной сборке. Проверка загрузки описана в [SECURITY.md](../SECURITY.md).

## Добавление компьютера

Откройте **«Мои компьютеры» → «Добавить компьютер»**. Укажите название, локальный IPv4 или hostname и нужные возможности. Дополнительный адрес используйте, если устройство доступно через уже настроенный VPN или другую разрешённую сеть.

Для SSH укажите имя пользователя. Для Wake-on-LAN добавьте MAC, broadcast IPv4 и UDP-порт. Сохраните карточку и обновите статус.

| Действие | Результат |
|---|---|
| Рабочий стол | Проверка RDP и открытие системного клиента. |
| Терминал | Проверка SSH и открытие системного терминала. |
| Включить | Отправка Wake-on-LAN; включение зависит от оборудования и сети. |
| Включить и подключиться | Отправка WoL, ожидание RDP и открытие клиента. |
| Включить и открыть терминал | Отправка WoL, ожидание SSH и открытие терминала. |

Авторизация выполняется в открывшемся клиенте. Ожидание подключения можно отменить.

## Где находятся данные

Список устройств и настройки остаются на ПК с NEXUS. Профиль приложения находится в `%APPDATA%\NEXUS CONTROL`. Перед резервным копированием профиля закройте приложение; храните копию в месте, доступном только вам.

Внешний вид меняется в настройках интерфейса. Если нужны инструкции по подключению, откройте встроенный **NEXUS GUIDE**: справочник работает без интернета.

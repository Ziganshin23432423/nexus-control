# История изменений

## 1.0.0-rc.1 — первый публичный Release Candidate

Предварительный выпуск для Windows 10/11 x64.

- Сохранение компьютеров, параметров подключения и заметок.
- Проверка доступности RDP и SSH по локальному и дополнительному адресу.
- Открытие удалённого рабочего стола и SSH-терминала через системные клиенты.
- Wake-on-LAN и сценарии «включить → дождаться → подключиться» для RDP и SSH.
- Локальный NEXUS GUIDE с поиском и помощью по настройке.
- Настройка эффектов и плотности интерфейса.
- Локальное хранение данных без облачной учётной записи и телеметрии.

Сборка unsigned, поставляется в ZIP. Wake-on-LAN требует поддержки со стороны оборудования и сети. Installer и автоматическое обновление не входят в этот выпуск.

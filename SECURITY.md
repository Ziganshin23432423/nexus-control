# Безопасность и приватность

NEXUS CONTROL предназначен для управления собственными компьютерами и устройствами, на доступ к которым у вас есть разрешение.

## Работа с данными

- Список компьютеров, адреса, имена пользователей SSH, MAC и заметки хранятся локально.
- Приложение не хранит пароли Windows или SSH и не отправляет телеметрию.
- Облачная учётная запись NEXUS и отдельный фоновый агент для базовых возможностей не требуются.
- Авторизацию выполняют системные RDP- и SSH-клиенты. Проверку SSH host key выполняет OpenSSH.
- Настройки системного клиента, включая его сохранённые учётные данные, управляются самим клиентом.

Не включайте пароли, приватные ключи и другую секретную информацию в названия или заметки устройств.

## Подключение

Используйте доверенную локальную сеть или настроенный защищённый VPN. Для удалённого доступа разрешайте только нужных пользователей и сохраняйте стандартные проверки безопасности системных клиентов.

Отправка Wake-on-LAN не подтверждает физическое включение компьютера. Ответ TCP-порта не подтверждает вашу авторизацию. NEXUS не меняет автоматически firewall, BIOS/UEFI или службы Windows.

## Проверка загрузки

Скачивайте приложение из [GitHub Releases этого репозитория](https://github.com/Ziganshin23432423/nexus-control/releases). Сравните SHA-256 скачанного ZIP с записью в `SHA256SUMS.txt` из того же релиза:

```powershell
Get-FileHash .\NEXUS-CONTROL-Windows-x64-1.0.0-rc.1.zip -Algorithm SHA256
```

Контрольная сумма помогает обнаружить изменение или повреждение файла; она не заменяет цифровую подпись. Сборка `1.0.0-rc.1` не подписана.

## Сообщение об уязвимости

Если в разделе **Security → Advisories** доступна кнопка **Report a vulnerability**, используйте её для приватного сообщения владельцу репозитория. Укажите версию, условия воспроизведения и влияние проблемы, не добавляя реальные пароли или личные данные.

Если приватное сообщение недоступно, создайте обычный Issue с просьбой согласовать закрытый канал связи. До согласования не публикуйте детали эксплуатации, секреты или сведения о чужих устройствах. Обычные ошибки интерфейса можно описывать в Issues после удаления личных данных.

Текущий выпуск имеет статус Release Candidate. Сроки исправления и поддержка предыдущих версий пока не объявлены.
